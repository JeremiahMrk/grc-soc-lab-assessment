# Disclaimer

This repository is a personal academic / portfolio GRC self-assessment of an Automated SOC Home Lab owned and operated by Jeremiah Mark.

It is intended to demonstrate governance, risk, compliance, evidence management, control assessment, risk treatment, and security-audit methodology in a controlled lab environment.

## This repository is not

- an independent audit
- a third-party assurance engagement
- an ISO/IEC 27001 certification assessment
- an accredited conformity assessment
- legal advice
- a formal determination of compliance with Indonesian law or UU PDP
- an assessment of a client or production enterprise environment

## Independence limitation

The lab is operated by one person, and some assessment work reviews controls or remediation implemented by that same person. This creates a self-review limitation. The original project explicitly records that limitation, and this public repository therefore uses the term **self-assessment** rather than independent audit.

## Security-sensitive information

The public portfolio is intentionally sanitized. Credentials, authentication material, raw vulnerability evidence, unnecessary private network details, security-sensitive configuration, and reusable attack paths are omitted.

## Framework references

ISO/IEC 27001:2022 and NIST CSF 2.0 are used as learning and assessment references. Their use in this repository does not imply endorsement, certification, or full organizational implementation.
