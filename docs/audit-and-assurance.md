# Internal Control Testing and Assurance Limitations

## Control-Testing Approach

The project includes a structured internal control-testing phase based on predefined criteria rather than narrative-only review.

The final audit checklist contains **13 test items**. In the final review, **12 tests were executed and one test could not be performed during the audit window**.

The testing approach emphasized:

- defining pass/fail criteria before execution
- preserving actual test results even when they contradicted expectations
- using repeatable technical checks where appropriate
- requiring negative tests for preventive controls
- requiring persistence evidence for controls that must survive restart/reboot
- recording unavailable tests as unavailable rather than forcing a pass/fail result

## Self-Review Threat

This is a personal lab operated by one person.

The same individual performed remediation work and later assessed parts of that work. This creates a **self-review threat** and means the work does not satisfy the independence expected from an independent internal-audit function.

The project explicitly documents this limitation instead of hiding it.

Accordingly, the public portfolio describes the work as:

- self-assessment
- internal control testing in a personal lab
- limited assurance / learning exercise

It does **not** describe the work as:

- an independent audit
- third-party assurance
- accredited certification work
- a professional client audit

## Findings and Corrective Action

The audit-report phase classifies control-test results, identifies nonconformities/observations, considers root causes, and tracks corrective actions.

The final project baseline records **13 corrective-action items**, with **8 closed** at the final review point. Open or accepted items were retained rather than silently marked complete.

## Why This Matters

For portfolio purposes, the strongest signal is not that every control passed.

The stronger signal is that the project:

1. set criteria before testing,
2. retained failed and unavailable results,
3. documented independence limitations,
4. used evidence to support conclusions,
5. tracked corrective actions instead of equating documentation with remediation.
