# Framework Mapping

## Purpose

The project includes cross-framework mapping to connect technical controls and governance decisions across multiple references.

Primary references:

- ISO/IEC 27001:2022
- NIST Cybersecurity Framework 2.0
- Indonesian UU PDP in a limited academic analytical context

## ISO/IEC 27001:2022

ISO/IEC 27001:2022 provides the main ISMS and control-assessment structure for the project, including scoping, risk treatment, Annex A control analysis, Statement of Applicability, internal-audit concepts, and corrective action.

## NIST Cybersecurity Framework 2.0

NIST CSF 2.0 is used as a complementary governance and cybersecurity-risk reference to connect lab activities with functions and outcomes such as governance, identification, protection, detection, response, and recovery.

## UU PDP Mapping

The project includes a limited academic mapping to selected Indonesian personal-data-protection concepts where relevant.

This portion is strictly an analytical exercise. It is **not**:

- legal advice
- a legal-compliance determination
- proof that an organization or system complies with UU PDP
- an assessment conducted by legal counsel or a regulator

## Mapping Principle

Cross-framework mapping is used to show relationships between security activities and governance expectations, not to manufacture compliance claims.

Where a framework requirement is outside the personal lab's scope, the repository preserves that limitation instead of implying full organizational coverage.
